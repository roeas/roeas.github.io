VS2022 使用窍门

本文最后更新于 2025-03-11T01:43:45+08:00

快捷键

常见

  • ctrl + Q，功能搜索
  • ctrl + W，选择光标所在的单词
  • ctrl + R + R，重命名光标所在的单词
  • ctrl + T，代码搜索
  • ctrl + A，全选
  • ctrl + shift + A，添加新文件
  • ctrl + S，保存当前文件
  • ctrl + shift + S，保存所有文件
  • ctrl + D，复制光标所在的行
  • ctrl + F，查找与替换
  • ctrl + shift + F，高级查找与替换
  • ctrl + G，跳转目标行
  • ctrl + Z，撤回
  • ctrl + shift + Z，重做
  • ctrl + X，剪切光标所在行
  • ctrl + C，复制
  • ctrl + V，粘贴
  • ctrl + shift + V，打开剪切板
  • ctrl + B，生成当前项目
  • ctrl + shift + B，生成解决方案
  • alt + 上下键，移动光标所在行

便利

  • ctrl + R + W，显示空白区域
  • ctrl + K + D，格式化当前文档
  • ctrl + K + S，插入代码模板
  • ctrl + L，剪切当前行
  • ctrl + shift + L，删除当前行
  • ctrl + ;，搜索解决方案资源管理器
  • ctrl + ,，代码搜索
  • ctrl + /，注释 / 取消注释
  • ctrl + alt + B，显示所有断点

光标 / 面板移动

  • ctrl + tab，面板导航
  • ctrl + 上下键，滚动页面
  • ctrl + 左右键，以连续的字符串为单位移动光标
  • ctrl + alt + 下键，选项卡导航
  • ctrl + alt + 左右键，以单词（以驼峰、数字、符号划分）为单位移动光标
  • home，移动光标到行首
  • end，移动光标到行尾
  • shift，按住框选，可以配合上述的光标移动方式
  • alt + 鼠标，跨行框选
  • alt + shift + 方向键，跨行框选
  1. alt + shift + 上下键跨行之后再用ctrl + shift + 左右键可以方便的处理排列在一起的长短不一的枚举 / 宏
  2. 代码搜索真的很好用，可以替代很多搜索 / 导航方式了

代码规范 / 书写习惯

本文最后更新于 2025-03-03T22:16:41+08:00

  • 第三方库使用 <> 而非 “”

  • 头文件包含顺序，清理不必要的头文件

  • 命名空间大括号向左缩进

  • 命名空间右大括号注释

  • 命名规范，member，pointer, static

  • 注释，does not instead of doesn’t

  • 注释，非英文的部分用 `` 括起来

  • 前向声明

  • [[nodiscard]]

  • final 和 explicit，不过 explicit 偶尔会很麻烦

  • 成员可访问级别

  • 三五法则

  • 提供参数为右值的重载函数，传值就完事了，实现内再 move

  • 将参数作为索引时用 const T&，当 sizeof(T) < 8 时不用 &

  • 用 const 修饰 this 指针

  • 用 string_view 代替 string

  • 尽量用 assert 代替 if check log，C++ 最好的错误检查就是崩在一个合理的地方
